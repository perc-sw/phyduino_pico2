Introduction to Electronics - Phyduino Pico2

An Arduino Uno-style development board built around the Raspberry Pi RP2350 microcontroller, and designed for the Introduction to Electronics course. Students learn surface-mount soldering techniques, microcontroller programming, analog-to-digital conversion and digital communication.
