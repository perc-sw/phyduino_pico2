Reset and UF2 button plan

Replace the XC6190 so that a short press resets the RP2350 and a long press restarts it in UF2 (BOOTSEL) mode.

Board appears as a USB drive. The hold time is set by one capacitor.

Why change it

The current XC6190 only resets when both of its inputs are held low together. One goes to SW1 and the other to the header RESET pin, which normally floats high, so pressing SW1 does nothing. The boot slide switch (SW2) is also easy to leave in the wrong position.

How it works

The RP2350 starts in UF2 mode if its flash chip-select (QSPI_SS) is low at the moment RUN is released. On a long press, the IC pulls INT and RESET low together, but RESET stays low longer. With INT driving RUN and RESET driving chip-select, chip-select is still low when the chip comes out of reset. Timings are not to scale.

Button (PB) INT → RUN RESET → flash CS RP2350 in reset Running program UF2 mode

Short press

INT pulses low for 100 ms after 50 ms of pressing. RESET doesn't change.

Long press

When the hold reaches tLP, INT goes low for 200 ms and RESET for 500 ms. RUN is released while CS is still low, so the chip starts in UF2 mode.

Board changes

  1. Replace U4 (XC6190) with the TPS3424C11EF2ADRLR.New symbol and SOT-583-8 footprint (0.5 mm pitch), as an ADV_SMT part.
  2. Remove SW2 (boot slide switch).Its "normal" position connects BOOTMODE straight to +3.3 V, which would short against U4's RESET output. A solder jumper to GND is fine if you want a permanent UF2 option.
  3. Keep R49 at 4.7–5.1 kΩ.The RP2350 datasheet recommends about 4.7 kΩ to ground. That's low enough to overcome the internal pull-up on QSPI_SS, but doesn't affect the chip-select signal when the RP2350 drives it.
  4. Don't add a strong external pull-up on flash CS.QSPI_SS has an internal pull-up from reset, so CS reads high (normal boot) while U4's RESET output is off. A 10 kΩ pull-up would combine with R49 to hold CS at about 1 V during a long press. That isn't a reliable low, so UF2 mode could fail. If you want one for extra safety, use 100 kΩ or more (giving about 0.15 V during a long press).
  5. Remove R18.It only set the XC6190's delay.
  6. Reduce C57 to about 10 nF, or remove it.U4 already ignores presses shorter than 50 ms.
  7. Add the LPT capacitor (4.7 nF) and the PB pull-up (10–100 kΩ).
  8. Connect J2.3 (header RESET) directly to RUN.Remove the EXT_RESET net.
